# Programación 1 – Universidad Latina de Costa Rica

Ejercicios y prácticas que he ido haciendo en el curso de Programación 1.
Todo está hecho en **Java** con **NetBeans** (proyectos *Java with Ant*).

## Proyectos

| Proyecto | Tema |
|---|---|
| `Semana7` | Variables, tipos de datos, entrada con `Scanner`, factura con descuento (`if-else`), ciclos `while`, `do-while`, `switch` y `for` |
| `Contador_resp_usuario` | Contador con `while` hasta el número que indique el usuario |
| `Array` | Arreglo de `String` para registrar y mostrar nombres |
| `Semana_8` | Vectores y promedio de notas, `ArrayList` (agregar, modificar, eliminar) y métodos (calculadora) |
| `Practicas_en_casa` | Sistema de inventario con menú, arreglos, matriz y métodos |
| `Progra_Objetos` | Programación orientada a objetos: clase vehículo con atributos, constructor, getters/setters y métodos |
| `Practica_Semana_7` | Proyecto base (en blanco por ahora) |

## Cómo abrirlos

1. Clonar o descargar el repositorio.
2. En NetBeans: **File → Open Project** y elegir la carpeta del proyecto que se quiera abrir.
3. Ejecutar con **Run File** (Shift + F6) sobre la clase que tenga el `main`.

Los proyectos están configurados con JDK 26.
